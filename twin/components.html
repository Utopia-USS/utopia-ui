Copyable text

No visual twin: a plain, ellipsized text label at rest (textStyles.text, no distinguishing chrome) - its whole affordance is interactive behavior (clipboard copy on tap, hover tint, tooltip, snackbar confirmation) that a static HTML twin cannot demonstrate meaningfully. See lib/src/widget/text/utopia_copyable_text.dart.

Date picker

A tap-to-open date field. The closed trigger is a labeled-field (same chrome, same row - see the labeled-field specimens below) carrying a permanent calendar affordance, plus a clear affordance only when there is a date to clear. The trigger is a real focus stop, so focus and open both render as the shared field focus ring. The open calendar itself has no static specimen: the grid is Material's own CalendarDatePicker, restyled from the theme through utopiaDatePickerMaterialTheme, and mirroring its metrics in CSS would mean inventing values this system does not own.

Field wrapper

No visual twin as a standalone specimen: UtopiaFieldWrapper is the shared borderless chrome and interactive-height floor behind every field in this twin (.utopia-text-field__chrome, .utopia-search-field, .utopia-switch-field, .utopia-labeled-field all express its decoration/padding/min-height directly) - see the text-field, search-field, switch-field and labeled-field specimens for its rendered form. See lib/src/widget/wrapper/utopia_field_wrapper.dart.

Form layout

No visual twin: a scrollable-content-plus-pinned-bottom-bar layout shell with no fixed visual contract of its own (colors, radii, spacing all come from whatever content is passed in) - its rendered shape is fully visible in the dialog specimen above (UtopiaDialog.form composes it internally). See lib/src/widget/layout/utopia_form_layout.dart.

Multi widget

No visual twin: a pure composition helper (builds nested widgets from a flat list, innermost last) with no rendered appearance of its own. See lib/src/widget/misc/utopia_multi_widget.dart.

Overlay anchor

No visual twin: an anchoring/positioning behavior (dismissible popup beneath a trigger, via OverlayPortal + CompositedTransformFollower) with no fixed visual contract of its own - the popup chrome it anchors (card decoration + border) is the same recipe as .utopia-card, visible in the card specimen above. See lib/src/widget/overlay/utopia_overlay_anchor.dart.

Page wrapper

No visual twin: a pure layout-resolution behavior (derives a UtopiaPageType from the available width and exposes it to the subtree) with no rendered appearance of its own. See lib/src/widget/layout/utopia_page_wrapper.dart.
